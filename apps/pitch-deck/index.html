The Problem

Every platform speaks
a different language

🔒

Platform lock-in

Build on Salla? Everything is Salla-shaped. Switch to Medusa? Rewrite everything.

💸

Costly rewrites

Switching platforms costs $50K–$200K. Most merchants never switch — even when they should.

🔄

Fragmented ecosystem

Different APIs, different data shapes, different payment flows. No standard exists.

THE SAME PRODUCT, FOUR PLATFORMS:

// Salla
{ "name": "...", "price": { "amount": 10.00 } }
// Medusa
{ "title": "...", "amount": 1000 }
// Shopify
{ "title": "...", "priceRange": { ... } }
// WooCommerce
{ "name": "...", "regular_price": "10.00" }
The Solution

One interface. Any backend.

Commerce.js gives you a unified API for products, carts, orders, and customers that maps to any eCommerce platform.

Connect in 5 lines

import { createCommerce } from '@commercejs/core'
import { SallaAdapter } from '@commercejs/adapter-salla'

const commerce = createCommerce({
  adapter: new SallaAdapter({ token: env.SALLA_TOKEN })
})

Switch in 1 line

import { MedusaAdapter } from '@commercejs/adapter-medusa'

const commerce = createCommerce({
  adapter: new MedusaAdapter({ ... })
})

// Same code. Different backend. Zero rewrites.
