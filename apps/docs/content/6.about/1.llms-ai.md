This documentation site exposes its content through machine-readable formats so that AI coding assistants and chatbots can answer questions about CommerceJS accurately.

## LLM-Friendly Endpoints (nuxt-llms)

The site generates optimized text versions of the documentation at well-known URLs. AI tools can fetch these to get up-to-date knowledge:

| Endpoint | Content |
|---|---|
| `/llms.txt` | Compact overview — titles, descriptions, and links |
| `/llms-full.txt` | Complete documentation content in plain text |
| `/llms-small.txt` | Per-section summaries for token-efficient retrieval |

These follow the emerging [`llms.txt` convention](https://llmstxt.org/) that many documentation sites adopt for AI discoverability.

## MCP Server (@nuxtjs/mcp-toolkit)

The site also runs as a [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) server, enabling AI tools like Claude, Cursor, and Windsurf to query documentation content interactively.

### Connecting Your AI Tool

Add the docs MCP server to your tool's configuration:

```json [.cursor/mcp.json]
{
  "mcpServers": {
    "commercejs-docs": {
      "url": "https://commerce.js.org/mcp"
    }
  }
}
```

::tip
In development, use `http://localhost:3200/mcp` instead.
::
