The `@commercejs/hosted-checkout` is a full Nuxt application that provides a hosted checkout experience. Merchants create a session via API, redirect customers to the checkout URL, and receive webhook notifications when payment completes.

It supports **payment links**, **saved cards with OTP verification**, **delivery dispatch**, and **cart-based checkout**.

## How It Works

::hosted-checkout-sequence


## Running Locally

```bash
cd apps/hosted-checkout
cp .env.example .env  # Configure your Tap keys
pnpm dev
```

The checkout page is available at `http://localhost:3100`.

## Environment Variables

```bash [.env]
TAP_SECRET_KEY="sk_test_xxx"
TAP_PUBLIC_KEY="pk_test_xxx"
TAP_BASE_URL="https://api.tap.company/v2"
TAP_MERCHANT_ID="1632424"
APP_URL="http://localhost:3100"
DATABASE_URL="postgres://..."
```

| Variable | Description |
|---|---|
| `TAP_SECRET_KEY` | Tap secret key for server-side operations |
| `TAP_PUBLIC_KEY` | Tap public key for Tap Card SDK tokenization |
| `TAP_BASE_URL` | Tap API base URL |
| `TAP_MERCHANT_ID` | Tap merchant ID |
| `APP_URL` | Base URL for redirects and webhooks |
| `DATABASE_URL` | Neon Postgres connection string (for profiles & sessions) |

## Tap Card SDK Integration

The checkout pages use the [Tap Card SDK](https://developers.tap.company/docs/card-sdk-web) for PCI-compliant card tokenization. The `<tap-card>` web component renders inside the checkout page, and tokenization happens on Tap's servers.

```vue
<template>
  <tap-card
    ref="tapCard"
    :publicKey="tapPublicKey"
    :direction="'ltr'"
    @tokenize="onTokenize"
    @error="onError"
  />
</template>
```

The card element renders in the browser, and on submission the SDK returns a `tok_xxx` token that is sent to the server for charge creation. No raw card data touches your server.

## API Endpoints

### Sessions

#### POST /api/sessions

Create a new checkout session:

```ts
const response = await fetch('https://checkout.myapp.com/api/sessions', {
  method: 'POST',
  body: JSON.stringify({
    amount: 99.999,
    currency: 'BHD',
    orderId: 'order-001',
    channel: 'web',           // optional — 'web' | 'pos' | 'agent' | 'link'
    fulfillment: 'shipping',  // optional — smart default from channel
    expiresIn: 1800000,       // optional — TTL in ms (30 min)
  }),
})

const { id, checkoutUrl } = await response.json()
// Redirect customer to checkoutUrl
```

#### GET /api/sessions/:id

Get the current session state:

```ts
const session = await fetch(`/api/sessions/${sessionId}`)
// Returns CheckoutSnapshot (includes channel, fulfillment, expiresAt)
```

#### POST /api/sessions/:id/pay

Submit payment with a tokenized card:

```ts
const result = await fetch(`/api/sessions/${sessionId}/pay`, {
  method: 'POST',
  body: JSON.stringify({
    sourceToken: 'tok_xxx',  // From Tap Card SDK
    customerInfo: { email, firstName, lastName, phone },
    shippingAddress: { street, city, country },
  }),
})
```

#### POST /api/sessions/:id/confirm

Confirm payment after 3DS redirect:

```ts
const result = await fetch(`/api/sessions/${sessionId}/confirm`, {
  method: 'POST',
  body: JSON.stringify({ chargeId: 'chg_xxx' }),
})
```

### Payment Links

#### POST /api/payment-links

Create a payment link with a QR code — ideal for POS terminals, AI agents, or messaging:

```ts
const response = await fetch('https://checkout.myapp.com/api/payment-links', {
  method: 'POST',
  body: JSON.stringify({
    amount: 45.00,
    currency: 'SAR',
    channel: 'pos',           // defaults to 'link' if omitted
    orderId: 'table-7',
    expiresIn: 1800000,       // 30 min (default)
    customerInfo: {           // optional — pre-fill
      email: 'walk-in@pos.local',
    },
  }),
})

const { sessionId, url, qrDataUrl, expiresAt } = await response.json()
// url → "https://checkout.myapp.com/pay/pl_xxx"
// qrDataUrl → "data:image/png;base64,..." (300×300 QR code)
```

| Field | Type | Description |
|---|---|---|
| `sessionId` | `string` | Unique session ID (`pl_` prefix) |
| `url` | `string` | Checkout URL for the customer |
| `qrDataUrl` | `string` | QR code as a PNG data URL |
| `expiresAt` | `string \| null` | ISO 8601 expiry timestamp |

### Profile & Saved Cards

The checkout supports buyer profile lookup and saved card checkout via OTP verification.

#### POST /api/profile/lookup

Look up an existing buyer profile by email or phone:

```ts
const response = await fetch('/api/profile/lookup', {
  method: 'POST',
  body: JSON.stringify({ phone: '+966500000000' }),
})
// Returns profile with saved addresses and payment methods
```

#### POST /api/profile

Create or update a buyer profile:

```ts
await fetch('/api/profile', {
  method: 'POST',
  body: JSON.stringify({
    email: 'buyer@example.com',
    phone: '+966500000000',
    firstName: 'Ahmed',
  }),
})
```

#### POST /api/profile/otp/send

Send an OTP code for profile verification:

```ts
await fetch('/api/profile/otp/send', {
  method: 'POST',
  body: JSON.stringify({ profileId: 'profile_123' }),
})
```

#### POST /api/profile/otp/verify

Verify the OTP code:

```ts
const result = await fetch('/api/profile/otp/verify', {
  method: 'POST',
  body: JSON.stringify({ profileId: 'profile_123', code: '1234' }),
})
```

#### GET /api/profile/cards

Get saved payment methods for a verified profile:

```ts
const cards = await fetch(`/api/profile/cards?profileId=profile_123`)
// Returns saved cards (last4, brand, expiry — no raw tokens)
```

#### POST /api/profile/cards/tokenize

Save a new card to the buyer profile:

```ts
await fetch('/api/profile/cards/tokenize', {
  method: 'POST',
  body: JSON.stringify({
    profileId: 'profile_123',
    sourceToken: 'tok_xxx',
  }),
})
```

### Delivery

#### POST /api/delivery-estimate

Get delivery fee estimates:

```ts
const estimate = await fetch('/api/delivery-estimate', {
  method: 'POST',
  body: JSON.stringify({
    origin: { latitude: 24.7136, longitude: 46.6753 },
    destination: { latitude: 24.7743, longitude: 46.7386 },
  }),
})
```

#### POST /api/delivery-dispatch

Dispatch a delivery order after checkout:

```ts
await fetch('/api/delivery-dispatch', {
  method: 'POST',
  body: JSON.stringify({
    orderId: 'order-123',
    origin: { branchId: '...' },
    destination: { ... },
  }),
})
```

### Cart Checkout

A cart-based checkout flow for embedded storefront integration:

#### GET /api/cart

Get the cart for the current checkout session.

#### POST /api/cart-pay

Submit payment for a cart-based checkout.

#### GET /api/cart-confirm

Confirm cart payment after 3DS redirect.

The `/pay/cart` page provides the UI for this flow.

### Webhooks

#### POST /api/webhooks/tap-payment

Receives async charge results from Tap. Verifies the webhook signature and updates the session/order state.

#### POST /api/webhooks/tap-connect

Handles Tap Connect OAuth callbacks for multi-merchant onboarding.

### Multi-Merchant

#### POST /api/merchants/:merchantId/payment-config

Register Tap payment credentials for a specific merchant:

```ts
await fetch(`/api/merchants/${merchantId}/payment-config`, {
  method: 'POST',
  body: JSON.stringify({
    tapSecretKey: 'sk_...',
    tapPublicKey: 'pk_...',
    tapMerchantId: '...',
  }),
})
```

## Payment Link Page

The `/pay/[id]` page provides a simplified checkout flow for payment links:

- **No address step** — skips shipping for `pickup` and `none` fulfillment
- **Expiry countdown** — shows remaining time before the link expires
- **Saved card support** — returning buyers can pay with saved cards via OTP
- **Minimal form** — email, name, phone, and card details
- **Tap Card SDK** — PCI-compliant card tokenization

## Multi-Merchant Support

The hosted checkout supports multi-merchant scenarios through a merchant configuration store. Each merchant registers their Tap credentials, and the checkout resolves the correct keys at runtime.
