Preview Environments
Every PR gets its own database

Open a pull request and Commerce.js Cloud automatically creates a full preview environment — complete with a branched Neon Postgres database, Cloudflare Pages deployment, and KV cache namespace.

Merge the PR and everything tears down. Zero configuration. Zero leaked resources.

Branch-per-PR Auto-cleanup Isolated data

Multi-Backend
Deploy any backend

Commerce.js Cloud isn't locked to one backend. Connect Salla, Medusa, or the built-in Platform engine. Your storefront code stays the same — only the adapter changes.

Start with the Platform engine (zero dependencies). Migrate to Salla when you scale. Switch to Medusa for international. One storefront, any backend.

// commercejs.config.ts export default defineCommerceConfig({ adapter: 'platform', // Built-in // adapter: 'salla', // Salla API // adapter: 'medusa', // Medusa v2 // adapter: 'shopify', // Coming soon payment: 'tap', notification: 'resend', analytics: 'ga4', })
