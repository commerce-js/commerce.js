# Preferences

## Coding Style
- Keep Prisma at parity with Drizzle — always add Prisma equivalents when adding Drizzle queries
- Prefer clean, robust, non-fragile architecture over clever solutions
- Avoid unnecessary complexity — solve the problem that exists, not theoretical ones

## Workflow
- Use `.memory/` for cross-session persistence, not just skills/rules
- Update `.plans/` in the same commit as the work, never defer
