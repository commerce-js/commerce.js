# T04: Dashboard Project Persistence

---

**Status**: 🟡 **Planned**
**Effort**: Medium
**Blocked By**: T03 (CLI deploy should work first to validate the orchestration)

## Goal

Add project persistence to the dashboard — create D1 tables for Cloud projects, deployments, and env vars so the dashboard can manage stores.

## Context

The dashboard Nuxt app is already configured with NuxtHub D1 (`hub.database: true`), but has no tables or schema for Cloud projects. This task adds the persistence layer that T05 will wire to the deploy orchestrator.

## Requirements

### 1. D1 Schema (via Drizzle)

Tables needed:

```
projects:
  - id (text, primary key, ULID)
  - name (text, unique)
  - subdomain (text, unique)
  - custom_domain (text, nullable)
  - repo_url (text, nullable)
  - plan (text, default 'starter')
  - neon_project_id (text, nullable)
  - cf_pages_project (text, nullable)
  - status (text: 'active' | 'suspended' | 'deleted')
  - owner_id (text)
  - created_at (text, ISO timestamp)
  - updated_at (text, ISO timestamp)

deployments:
  - id (text, primary key, ULID)
  - project_id (text, FK → projects.id)
  - environment (text: 'production' | 'staging' | 'preview')
  - status (text: 'building' | 'deploying' | 'ready' | 'failed')
  - url (text)
  - commit_sha (text, nullable)
  - branch (text, nullable)
  - build_log (text, nullable)
  - error (text, nullable)
  - build_duration_ms (integer, nullable)
  - deployed_at (text, ISO timestamp)

project_env_vars:
  - id (text, primary key, ULID)
  - project_id (text, FK → projects.id)
  - key (text)
  - value (text, encrypted at rest)
  - environment (text: 'production' | 'staging' | 'all')
  - created_at (text, ISO timestamp)
```

### 2. Server API Routes

- `POST /api/projects` — Create project
- `GET /api/projects` — List projects (for project list page)
- `GET /api/projects/:id` — Get project details
- `PATCH /api/projects/:id` — Update project settings
- `DELETE /api/projects/:id` — Delete project (soft delete → status: 'deleted')
- `GET /api/projects/:id/deployments` — List deployments
- `POST /api/projects/:id/env` — Set env var
- `GET /api/projects/:id/env` — List env vars (values masked)
- `DELETE /api/projects/:id/env/:envId` — Delete env var

### 3. Integration Points

- Uses NuxtHub's `hubDatabase()` for D1 access
- Drizzle ORM for type-safe queries
- ULID for IDs (consistent with rest of Commerce.js)
