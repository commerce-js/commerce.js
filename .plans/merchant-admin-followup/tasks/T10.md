# T10: Inventory inline + low-stock

---

**Status**: 🟡 **Planned**
**Effort**: Small
**Blocked By**: None — `admin.updateInventory` / `getLowStockProducts` already exist.

## Goal

A logged-in merchant can see which products are low on stock and adjust
quantities inline. No bulk CSV import (deferred to v2).

## Context

Platform exposes:

- `admin.updateInventory({ productId, variantId?, quantity, adjustment? })`
  where `adjustment` is `'set' | 'increment' | 'decrement'`.
- `admin.getLowStockProducts(threshold?: number): Promise<Product[]>`.

T10 wraps these into one page + two routes. Bulk CSV import is explicitly
deferred — mentioned in the plan's "Out of scope" list.

## Requirements

### 1. API routes under `apps/dashboard/server/api/admin/inventory`

- `index.get.ts` — `?threshold=` (default 10) → `admin.getLowStockProducts(threshold)`.
- `update.post.ts` — body `{productId, variantId?, quantity, adjustment}`
  → `admin.updateInventory(body)`.

All gated by `requireMerchantSession`.

### 2. Zod schema

`updateInventorySchema` mirrors `UpdateInventoryInput`:

```ts
export const updateInventorySchema = z.object({
  productId: z.string().min(1),
  variantId: z.string().optional(),
  quantity: z.number().int(),
  adjustment: z.enum(['set', 'increment', 'decrement']).optional(),
})
```

### 3. Page (`/admin/inventory.vue`)

Layout:

- **Threshold input** at top — numeric, default 10. Debounced
  (300 ms); changes re-fetch the list.
- **Table**: image thumbnail, name (EN + AR muted), SKU, current
  quantity, variant count (if > 0, shown as "N variants" muted), inline
  quantity input + mode selector (set / +/−) + Apply button.
- **Empty state**: "Nothing below threshold N." with a subhead
  suggesting a lower threshold.
- Apply button POSTs `/api/admin/inventory/update` → success toast →
  refresh row (or full list).

### 4. Variant handling

If a product has variants, T10 v1 only edits product-level quantity (via
`productId`). Inline per-variant editing is deferred — click-through to
the product edit page (T03's `/admin/products/[id]/edit`) which already
has variant fields in `AdminProductForm`. Surface a helper link in the
inventory row.

### 5. Sidebar link

Add "Inventory" to `apps/storefront/app/layouts/admin.vue` between
Products and Orders.

## Test Scenarios

- [ ] List with threshold=10 shows all smoke products (they're all
      inventoryQuantity=null or high).
- [ ] Lower threshold to 1 → shows only truly-low items.
- [ ] `POST /update` with `adjustment: 'set', quantity: 50` → product's
      inventory becomes 50; next list excludes it (if threshold=10).
- [ ] `POST /update` with `adjustment: 'increment', quantity: 5` → +5.
- [ ] `POST /update` with negative `decrement` beyond 0 → platform
      should clamp at 0 or return an error; document the behavior.
- [ ] Cross-tenant + unauth as in T05.

## Implementation Notes

- **No CSV / bulk path**. If a merchant asks, point to the Deferred list
  and let the email-workstream-adjacent v2 plan pick it up.
- **Threshold default (10)**: consistent with platform default; can be
  made per-merchant-configurable in a v2.
- **Confirm before large decrements**: decrement > 10 in one go should
  prompt a "sure?" modal — guards against typos.
