# T02: Layout, Theme & Design System

---

**Status**: 🟡 **Planned**
**Effort**: Medium
**Blocked By**: T01

## Goal

Create the default layout with header, footer, navigation, and a polished design system using Nuxt UI v4 semantic colors and theming.

## Requirements

### 1. Default Layout
- `UHeader` with logo, navigation links (Home, Products, Categories), cart icon with count badge
- `UFooter` with store info from `useStoreInfo`
- `UMain` for page content
- Mobile-responsive via Nuxt UI built-in responsiveness
- Color mode toggle (`UColorModeButton`)

### 2. Theme Configuration
- Primary: `indigo`
- Neutral: `slate`
- Custom CSS variables for premium feel
- Rounded corners, smooth transitions

### 3. Components
- `AppHeader.vue` — navigation, cart icon, search
- `AppFooter.vue` — store info, links
- `ProductCard.vue` — reusable product card with image, price, badge
