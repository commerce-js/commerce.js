# T02: New Composables (useBrands, useCountries, useLocations)

---

**Status**: 🟡 **Planned**
**Effort**: Small
**Blocked By**: None

## Goal

Create 3 new composables for Tier 2 data following the established `useStoreInfo` pattern — fetch-and-cache with `useState`, `readonly`, error wrapping.

## Context

API routes for `/brands`, `/countries`, `/locations` already exist. The composables provide a reactive interface on the client side. They follow the same uniform pattern as `useStoreInfo`.

## Requirements

### 1. `useBrands` Composable

- Calls `adapter.getBrands()`
- Returns `{ brands, loading, error, refresh }`
- State key: `commerce:brands`

### 2. `useCountries` Composable

- Calls `adapter.getCountries()`
- Returns `{ countries, loading, error, refresh }`
- State key: `commerce:countries`

### 3. `useLocations` Composable

- Calls `adapter.getStoreLocations()`
- Returns `{ locations, loading, error, refresh }`
- State key: `commerce:locations`

### 4. Registration

- Export all 3 from `composables/index.ts`
