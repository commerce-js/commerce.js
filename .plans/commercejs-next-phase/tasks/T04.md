## Goal

Validate the full Nuxt stack end-to-end: module → Nitro plugin → API routes → Salla adapter → real Salla API. Confirm that products, categories, store info, brands, countries, and locations all return real data.

## Context

All pieces are built — this task proves they work together. We create a minimal Nuxt app, configure it with `@commercejs/core`, and hit the API routes.

## Requirements

### 1. Test Script

Create a test script that hits the API routes via `$fetch` or `curl` and validates:
- `GET /api/_commerce/products` — returns products
- `GET /api/_commerce/categories` — returns categories
- `GET /api/_commerce/store` — returns store info
- `GET /api/_commerce/brands` — returns brands
- `GET /api/_commerce/countries` — returns countries
- `GET /api/_commerce/locations` — returns locations

### 2. Build Verification

- All 3 packages build without errors
- `pnpm turbo build --filter=@commercejs/core`
