# T01: Scaffold Nuxt App

---

**Status**: 🟡 **Planned**
**Effort**: Small
**Blocked By**: None

## Goal

Create a new Nuxt 3 app at `packages/storefront` with `@nuxt/ui` v4 and `@commercejs/core` configured as a module.

## Requirements

### 1. Project Setup
- Create `packages/storefront` directory
- `nuxt.config.ts` with `@nuxt/ui` and `@commercejs/core` modules
- `app.vue` with `UApp` wrapper
- `assets/css/main.css` with Tailwind + Nuxt UI imports
- `app.config.ts` with color scheme
- `.env` with Salla credentials (symlink or copy from adapter-salla)

### 2. Package.json
- Workspace dependencies: `@commercejs/core`, `@commercejs/types`
- Dependencies: `@nuxt/ui`, `nuxt`, `vue`

### 3. Verify
- `pnpm install` resolves workspace links
- `pnpm --filter=storefront dev` starts the dev server
