# T05: Product Detail Page

---

**Status**: 🟡 **Planned**
**Effort**: Medium
**Blocked By**: T02

## Goal

Build a rich product detail page with image gallery, variant selection, reviews, and add-to-cart.

## Requirements

### 1. Product Detail (`/products/[id]`)
- Image gallery with `UCarousel`
- Product info: name, price, description, badges
- Variant selector (color, size) using `USelect`
- Add to cart button
- Reviews section using `useReviews`

### 2. Reviews
- Average rating display
- Review list with pagination
- Review submission form (if authenticated)
