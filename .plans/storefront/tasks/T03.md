**Status**: 🟡 **Planned**
**Effort**: Medium

## Goal

Build a premium homepage showcasing the store: hero banner, featured products carousel, category grid, and brands section.

## Requirements

### 1. Hero Section
- Full-width hero with gradient overlay
- Store name from `useStoreInfo`
- CTA button linking to products

### 2. Featured Products
- `UCarousel` with `ProductCard` components
- Uses `useProducts` to fetch featured/latest products

### 3. Category Grid
- Grid of categories with images using `UCard`
- Uses `useCategories`
- Links to `/categories/[id]`

### 4. Brands Section
- Logo grid using `useBrands`
- Uses `UPageLogos` or custom grid
