# T04: Product Listing & Category Pages

---

**Status**: 🟡 **Planned**
**Effort**: Medium
**Blocked By**: T02

## Goal

Build product listing with filtering, sorting, pagination, and category-specific views.

## Requirements

### 1. Product Listing Page (`/products`)
- Grid of `ProductCard` components
- `UPagination` for paginated results
- Search input with debounce
- Category filter sidebar
- Sort options (price, name, newest)

### 2. Category Page (`/categories/[id]`)
- Same grid layout but filtered by category
- Breadcrumb showing category path
- Uses `useProducts` with category filter
